# Fintech FIAP — Your Bank

Projeto acadêmico de interface web para uma aplicação financeira, desenvolvido durante a formação em **Análise e Desenvolvimento de Sistemas na FIAP**.

A proposta do projeto é representar uma experiência digital de banco/fintech, com páginas e componentes voltados à navegação e apresentação de informações financeiras.

---

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

---

## 📁 Estrutura do Projeto

```text
fintech_fiap/
├── images/
├── js/
├── pages/
├── styles/
├── index.html
└── README.md
```

A estrutura separa:

- páginas da aplicação;
- estilos;
- scripts;
- imagens e recursos visuais.

---

## 🎯 Objetivo

O projeto foi criado para praticar conceitos de:

- desenvolvimento web;
- estruturação de páginas;
- estilização;
- responsividade;
- organização de arquivos;
- experiência de usuário em aplicações financeiras.

---

## 🧠 Aprendizados

Durante o desenvolvimento foram trabalhados fundamentos importantes de Front-End, como:

- estruturação semântica com HTML;
- criação de interfaces com CSS;
- organização de assets e scripts;
- comportamento básico com JavaScript;
- construção de páginas responsivas;
- organização de uma aplicação web em múltiplas telas.

---

## 🗺️ Evolução do Projeto

Este projeto representa uma etapa inicial da minha formação em desenvolvimento web.

A ideia futura é evoluir o conceito para uma aplicação financeira Full Stack mais completa, utilizando tecnologias modernas como:

- React
- TypeScript
- Java
- Spring Boot
- PostgreSQL
- Docker
- APIs REST
- autenticação
- testes
- CI/CD
- Inteligência Artificial aplicada a funcionalidades financeiras

Essa evolução dará origem ao projeto **BankAI**.
